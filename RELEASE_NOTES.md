# Canelé v1.1.1 Release Notes 🍮

> **Release Date:** September 3, 2026  
> **Target Platform:** Android (API 21+ / Android 5.0+)  
> **Tag:** `v1.1.1`

**Canelé v1.1.1** is a focused quality-of-life release streamlining volume cards, cleaning up the dashboard watchlist, refining the bottom navigation bar, and introducing amortized financial spend insights.

---

## 🌟 What's New in Canelé v1.1.1

### 🏷️ 1. Streamlined Volume Checklist Cards
- **Hidden Price on Gifts**: Volumes marked as gifts now hide the price tag completely, showing only the clear `GIFT` indicator.
- **Removed (Default) Suffix**: Cleaned up the price display by removing the `(Default)` text.

### 📋 2. De-Cluttered Dashboard Watchlist
- **Minimalist Watchlist Card**: Removed redundant status badges from watchlist item cards.
- **Focused Volume Information**: Cards now cleanly show only the series title, volume number, and release timing (`Released on <date>` or `Releases <date>`).

### 🧭 3. Streamlined Bottom Navigation Bar
- **Removed Icon Highlight Pill**: Removed the background highlight pill around the selected icon in both light and dark themes, using pure color highlighting instead.

### ⏱️ 4. Compact Exchange Rate Sync Cooldown
- **Hours-Only Cooldown Display**: Exchange rate sync cooldown timer now displays hours (e.g. `Next in 4h`, `8h`, `11h`), showing minutes only when less than 1 hour remains.

### 📊 5. Amortized Financial Spend Insights
- **Estimated Monthly & Annual Spend**: Expanded the Financial & Spend Insights card in Statistics with two new metrics:
  - **Est. Monthly Spend**: Shows an amortized monthly spending estimate calculated from total spend divided across all elapsed timeline months (from your timeline start date to today).
  - **Est. Annual Spend**: Projects your annualized collection spending pace over a 12-month period.
- **Canelé Amber Styling & Clean Labels**: All four financial metric figures now use the Canelé caramelized amber color, and the Total Spent subtitle has been simplified to *"Across all volumes"*.
- **Unified Card Layout**: Integrated directly into the existing financial card with a clean divider, keeping all cost and pace metrics unified in a single card.
